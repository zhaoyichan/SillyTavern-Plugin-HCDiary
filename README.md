# LIWE · RAG 记忆引擎（角色日记 / Character Diary）

一个功能强大的 **SillyTavern（ST）剧情记忆管理扩展插件**。它不只是写日记——它是一个完整的 **RAG（检索增强）记忆引擎**，为你的剧情自动沉淀记忆、构建人物关系、管理剧情脉络；内置 **「世界论坛 · 跨世界社区」**（各故事世界打通串门的社区论坛）与一套花样繁多的 **「仪式注入台」符契系统**，让 AI 的每次生成都更有仪式感、更有活人味。

> 别名：HCDiary · `character-diary` · LIWE · RAG 记忆引擎
> 运行环境：SillyTavern / Tauri Tavern（安卓客户端）

---

## ✨ 它能做什么

每次 AI 回复后，插件会并行分析新增剧情内容，自动完成多件事：

| 模块 | 说明 |
|------|------|
| 📖 **角色日记** | 为每个有戏份的角色以第一人称写日记（心情/态度/心声/关键事件） |
| 🔗 **人物关系网** | 提取角色间单向主观关系（友好/排斥/中立），力导向图可视化 |
| 📜 **剧情档案** | 增量更新主线/支线/状态/未解决事项 + 用户自定义追踪项 |
| 🧠 **RAG 记忆检索** | 向量化 + Rerank 重排，按需把相关回忆注入 AI，减轻上下文压力 |
| 🌐 **世界论坛** | 跨世界社区论坛：不同世界角色互刷/留言/吐槽/吃醋（详见下） |
| 🎲 **仪式注入台** | 内置多个可编辑的「符契」规则，注入 AI 生成过程（详见下） |
| 📋 **LIWE 情报表** | 可自定义的角色状态/履历填表，自动快照演进 |

## 🌐 世界论坛 · 跨世界社区

### 🎯 核心灵魂
不是一个个故事世界各玩各的——**所有故事世界打通串门**。
换人设、换全新故事剧本，之前的人物信息全都不会丢。
A 故事里的角色，能刷到 B 故事角色发的帖子，可以跑过去留言、互怼、吃瓜，甚至还会跨世界吃醋搞事情。

### ✅ 全部好玩功能一览

**1. 一键打包保存你的整个故事世界【基础核心】**
界面有很显眼的按钮：**总结当前剧情 · 保存世界**。
AI 自动帮你整理完整故事，同时处理三件事：① 这个世界是什么样子、故事发展到哪一步；② 主角是谁、都做过哪些事；③ 所有 NPC 性格、还有对你的好感度数值。
会读取全部聊天记录 + 最近 20 条对话做压缩存档，换故事也不会剧情断裂。
- 同一个聊天重复保存：同名的人物、剧情直接更新覆盖，没重复的内容全部保留；
- 切到别的聊天保存：直接新增一个全新世界，老世界完整保留、不会删。

**2. NPC 自己发帖吃瓜，还能跨世界串门唠嗑**
支持**自动 / 手动**两种模式。
- *自动模式*：角色产出各类话题（剧情、八卦、吐槽碎碎念、情感、扯皮玩梗都包含），支持开关成人向内容；多个世界的人物互相串门发帖、隔空互动产生内容。
- *手动模式*：你描述想要生成的内容，按描述产出帖子。
硬性规则：角色输出贴近普通人说话习惯，不会出现"分析、统计、综上所述"这类机器腔话术。

**3. 跨世界评论吃瓜，角色到处跑楼对线**
每一条帖子都会标注所属故事世界；别的世界的 NPC 可以在帖子下方写评论，来源会展示。不同世界的人物互相吃瓜吐槽、进入别人帖子下参与讨论、产出各类楼层回复内容。

**4. 点开名字直接看角色完整人设卡**
点角色名字或头像胶囊，弹出人物名片：名字、所属世界、性格、好感度（-100 到 100）、对你真实评价、专属小癖好。顶部「角色」入口可以浏览你拥有的全部人物。

**5. 会产生吃醋闹矛盾的行为，无需手动触发**
旧熟人看到你和别的新角色相处，好感数值会下降、输出偏向消极内容；会在帖子里和新角色产生冲突，也会对你表达不满。该效果跟随故事发展自动触发。

**6. 帖子为贴吧样式，阅读门槛低**
点开帖子，上方展示楼主完整正文（标注作者与所属世界），下方为楼层评论区；支持收藏帖子、手动撰写回复，也可以由 AI 生成角色回复。

**7. 4 个信息流板块，自由切换**
顶部四个标签：**全局 / 收藏 / 主页 / 管理**。
- 全局：浏览全部世界的所有帖子；收藏：查看你收藏过的帖子；
- 主页：只展示你自己发布的内容；管理：统一管理全部角色、全部故事世界。

**8. 你的专属主页，区分用户与 AI 角色**
可以设置个人发帖昵称，主页仅展示由你主动发布的帖子；AI 不会冒充用户发言，NPC 产出的帖子不会进入你的主页、不会盗用你的昵称输出。

**9. 发帖支持公开 / 隐私两种状态**
发帖输入框旁设置开关，默认公开。
- 公开：相关 NPC 可以浏览帖子并互动评论，发生的事件会写入人物记忆；
- 隐私：仅自己可见、NPC 无法浏览、不衍生后续剧情。

**10. 帖子发布身份区分**
你发布的帖子作者显示你设置的昵称；AI 生成帖子的作者均为故事内 NPC，与用户身份做隔离。

**11. 管理面板，全部内容直接展示**
顶部点「管理」：上半区展示全部角色、下半区展示全部故事世界，无需多层点击跳转。角色卡片包含头像/名字/所属世界/好感/性格/对你的评价/记恨清单/念念不忘清单，支持记忆编辑、新增删除人物、AI 一键总结人设；世界卡片包含世界名字/氛围/标签/世界观详情/主角经历/登场人物列表。

**12. 社交记忆系统【持续更新】**
发布公开帖子后，AI 判断会被事件影响的相关角色；**记仇与记好感**的状态会改变角色好感、并永久保存到角色档案。角色回复会读取过往全部恩怨记录，旧仇旧情会体现到对话中；被点名冒犯的角色可以前往对应帖子对峙回复；支持一键精简压缩人物记忆、清理多余内容。

**13. 设置界面内容精简**
设置页面只保留 AI 接口配置（来源地址 / 密钥 / 模型选择）；配置带确认弹窗的一键清空按钮，可批量删除世界、帖子、角色等全部相关数据。

**14. 自定义 AI 提示词**
整理世界观、生成帖子、制作人设、吃醋剧情共用一套调试完成的提示词；也可以手动修改提示词文本，自定义 AI 输出表现。

## 🎆 仪式注入台 · 符契系统

（v2.7+ 新增）一个独立的"场景模块库"，可手动开启一个个**符契（注入规则）**，让 AI 生成前注入特定约束，与记忆注入相互独立。每个符契可独立开关、编辑档位、设置注入位置（开头/对话中/末尾）。

| 符契 | 说明 |
|------|------|
| 🎲 **命运骰** | 跑团叙事判定：简单/困难两档，掷骰池+四档结果，思考过程折叠 |
| 🔥 **炼狱世界** | 地狱级生存法则：处处为难/人人怀疑/禁神话主角/绝境坚韧，带骰池判定 |
| 💖 **好感引擎** | 复杂化好感度系统：阶段区间/增减规则/阈值锁，原样/精简两档 |
| 📊 **状态栏** | RPG 状态面板：全面版=全数值(精神/体力/魔力/行动力等)；好感版=各角色对用户好感 |
| 🌌 **平行世界** | 同一时刻主线之外的他处事件，丰富剧情视角 |
| 💬 **弹幕** | 观众实时吐槽：普通版=毒舌乐子人氛围；黄色版=P站风格荤弹幕(只针对主角)，活人味十足（已去除贴圈子/相互骂架） |
| 🔮 **伏笔** | 隐藏伏笔/铺垫，服务于未来剧情 |
| 🌐 **论坛** | 世界论坛·跨世界社区（详见上方章节）：各世界角色互刷/留言/跨世界吃醋，贴吧神帖风 |
| 🖥️ **前端生成** | 用 HTML 具象化剧情界面/物品（手机聊天/书信/道具卡/HUD），直接可见 |

> 每个符契生成的动态内容默认用 `<details>` 折叠呈现（前端生成直接可见），不打断正文阅读。
> 全部提示词可编辑、可自建新符契、可一键恢复默认。

## 🧠 记忆与检索能力

- **RAG 向量检索**：剧情档案/角色日记向量化，命中相关回忆再注入
- **Rerank 重排**：OpenAI 兼容 `/rerank` 端点重排召回结果，失败自动降级
- **按登场人物注入**：正则识别剧情中出现的角色，只推这些角色的近期日记
- **选择性记忆（白名单）**：开启后只记「重点角色」，避免无关配角堆积
- **数据保护**：检测日记骤减自动从 localStorage 备份补回，防丢数据

## 🔧 其他亮点

- **三路并行 API** — 日记/关系/档案各自独立调用，单路失败不影响其他
- **自动/手动双模式** — 每 N 楼自动触发，也可手动指定范围补写
- **剧情时间线** — 主线/支线/状态/未解决分类展示，带时间标记
- **章回导航** — 自动生成章回标题，支持翻阅历史版本
- **世界书联动** — 别名字符归一化，精准命中原绑定角色的世界书条目
- **心理补全 / 名场面收藏 / 成就系统 / 塔罗占卜** 等趣味功能
- **填表功能（LIWE 情报表）** — 可自定义字段，自动快照
- **全量迁移** — 导出/导入聊天记录+插件回忆，换设备不丢记忆
- **Token 统计与费用** — 日志面板显示每次调用的 Token、缓存命中、费用估算

## 📥 安装方法

```bash
cd SillyTavern/extensions/
git clone https://github.com/zhaoyichan/SillyTavern-Plugin-HCDiary.git character-diary
```

重启 SillyTavern 后，在扩展菜单中点击「角色日记」即可使用。

---

## 🚀 使用快速上手

1. 右上角滑块进入**设置**，配置 API 来源（默认跟随酒馆）
2. 正常聊天，AI 回复后插件自动检测并写日记（或点「写日记」手动触发）
3. 「浏览」视图：查看所有角色日记；「时间线」看剧情档案演进；「关系」看关系网
4. 顶部「论坛」入口：进入**世界论坛**，点「总结当前剧情 · 保存世界」生成你的第一个世界档案，然后看各世界角色互刷帖子
5. 「更多菜单 → 仪式注入台」：开启你想要的符契（如命运骰、弹幕、论坛），感受注入效果
6. 「日志」视图：查看 API 调用详情、Token 与费用统计

---

## 💾 数据存储

- 日记/关系/剧情档案存在 ST 的 `chatMetadata.extensions['character-diary']`，跟随聊天自动保存，并有 Chat Variables 双轨兜底
- 世界论坛的世界/帖子/角色/称号存在 localStorage（`cd-forum-data`），换卡不丢，另有 settings 双轨
- 日志存储在浏览器 localStorage，刷新不丢失
- 可用「全量迁移」在换设备时完整搬迁记忆
