【SillyTavern 插件】LIWE · RAG 记忆引擎
专为长线RP创作者打造的一体化结构化记忆解决方案
不止简单对话总结，依托原生RAG架构，将世界观、人物关系、剧情变迁永久结构化沉淀，根治AI健忘、人设崩坏、剧情前后矛盾痛点。

────────────────────
🧠 四大核心能力矩阵
────────────────────
📜 剧情档案系统
· 自动归纳主线、支线脉络，留存关键状态与遗留伏笔
· 支持增量式内容融合压缩，段落节点一键精简梳理
· 自动生成剧情摘要、章回标题，搭建清晰完整时间线

📓 角色自传日记
· 独立为每名角色生成第一人称日记，记录心绪、对你的态度、重大事件与观念转变
· 多角色自动分区管理，支持检索筛选、随机回溯、情绪热力图可视化
· 支持手动补录历史楼层，勾选指定对话生成存档

🔍 向量检索增强(RAG)
· 剧情档案、角色日记双知识库独立向量化存储
· 对话自动检索相关历史记忆注入上下文，做到有据可查
· 共享嵌入API资源，区分剧情库/日记库两套索引，实现真正长效检索记忆

📋 智能填表（情报表模式）
· AI自动维护结构化全局情报表：场景地点、角色衣着/状态/好感、持有物品、任务进度、人物经历一览无余
· 使用折叠<details>组件输出情报，正文不刷屏，整洁不破坏对话观感
· 插件自动采集更新，支持自定义字段，增量刷新避免重复冗余

────────────────────
