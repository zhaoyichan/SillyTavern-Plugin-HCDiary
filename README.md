# LIWE · RAG 记忆引擎（角色日记 / Character Diary）

一个功能强大的 **SillyTavern（ST）剧情记忆管理扩展插件**。它不只是写日记——它是一个完整的 **RAG（检索增强）记忆引擎**，为你的剧情自动沉淀记忆、构建人物关系、管理剧情脉络，并内置 **游戏存档盘**、**世界论坛 · 跨世界社区**、**真图生图**、**小剧场**、**仪式注入台** 等一大套让角色"活起来"的玩法，让 AI 的每次生成都更有仪式感、更有活人味。

> 别名：HCDiary · `character-diary` · LIWE · RAG 记忆引擎
> 运行环境：SillyTavern / Tauri Tavern（安卓客户端）
> 当前版本：v2.17.0

---

## ✨ 它能做什么

每次 AI 回复后，插件会并行分析新增剧情内容，自动完成多件事：

| 模块 | 说明 |
|------|------|
| 📖 **角色日记** | 为每个有戏份的角色以第一人称写「活人感」私密日记（心情/态度/心声/关键事件），可选简单/复杂双档 |
| 🔗 **人物关系网** | 提取角色间单向主观关系（友好/排斥/中立），力导向图可视化 |
| 📜 **剧情档案** | 增量更新主线/支线/状态/未解决事项 + 用户自定义追踪项，支持自动压缩"瘦身不截肢" |
| 🧠 **RAG 记忆检索** | 向量化 + Rerank 重排，按需把相关回忆注入 AI，减轻上下文压力 |
| 🎮 **游戏存档盘** | RPG 游戏式存档：按角色存档、快照记忆、星标置顶、导出 zip/导入（详见下） |
| 🌐 **世界论坛** | 跨世界社区论坛：不同世界角色互刷/留言/吐槽/吃醋（详见下） |
| 🎨 **真图生图** | 图库/相册/看图、12 套绘图风格、可编辑提示词，让角色"看得见"（详见下） |
| 🎭 **小剧场** | 让 AI 演一段"沉浸式小剧场"，把某段剧情/设定用表演方式呈现 |
| 🔔 **回复提示音** | AI 回复整段生成完毕自动播放提示音，可自定义音频与触发时机 |
| 🎲 **仪式注入台** | 内置多个可编辑的「符契」规则，注入 AI 生成过程（详见下） |
| 📋 **LIWE 情报表** | 可自定义的角色状态/履历填表，自动快照演进 |

## 🎮 游戏存档盘（v2.16+）

像 RPG 游戏一样为你的每一个角色建一个**存档盘**，随时回到剧情的关键节点。

- **双屏结构**：第一屏「角色卡墙」选角色 → 第二屏「纵向槽位盘」看该角色的全部存档。
- **快照存档**：每份存档保存"那个时刻的最近 N 条对话（默认10，可自定义）+ 完整记忆快照（剧情/日记/关系/金额/未解决全保全）"，体积小又不会丢剧情。
- **追加不覆盖**：每次存档都追加新档，**绝不覆盖**旧档；每角色可存高达 100 格。
- **星标置顶**：重要存档打 ★ 自动排到最前。
- **每消息快捷存档**：每条消息左下角有常驻存档小图标，点一下直接弹命名窗，不用打开插件面板。
- **读档确认**：读档前居中弹窗提示，防止手滑点到旧档。
- **存档感言**：每份存档、每个角色都可以单独写纯记录性质的「感言」备注。
- **导出 / 导入**：导出为 zip 包（内含 data.json）长期保存，导入兼容 zip 与 json，换设备不丢。

## 🌐 世界论坛 · 跨世界社区

### 🎯 核心灵魂
不是一个个故事世界各玩各的——**所有故事世界打通串门**。
换人设、换全新故事剧本，之前的人物信息全都不会丢。A 故事里的角色，能刷到 B 故事角色发的帖子，可以跑过去留言、互怼、吃瓜，甚至还会跨世界吃醋搞事情。

### ✅ 全部好玩功能一览

**1. 一键打包保存你的整个故事世界【基础核心】**
界面有很显眼的按钮：**总结当前剧情 · 保存世界**。AI 自动帮你整理完整故事（世界观/主角/剧情进度/NPC 性格与好感），读取全部聊天记录 + 最近 20 条对话做压缩存档，换故事也不会剧情断裂。
- 同聊天重复保存：同名人物/剧情直接更新覆盖，没重复的全部保留；
- 切到别的聊天保存：新增一个全新世界，老世界完整保留。

**2. NPC 自己发帖吃瓜，还能跨世界串门唠嗑**
支持自动 / 手动两种模式。自动模式让角色产出各类话题（剧情、八卦、吐槽、情感、玩梗），可开关成人内容，多世界人物互相串门隔空互动；手动模式由你描述生成。角色输出贴近普通人说话习惯，不带机器腔。

**3. 跨世界评论吃瓜，角色到处跑楼对线**
每条帖子标注所属世界；别的世界的 NPC 可以评论串门、互怼吃瓜。

**4. 点开名字直接看角色完整人设卡**
点角色名字/头像弹人物名片：名字、所属世界、性格、好感度（-100~100）、对你的真实评价、专属小癖好。

**5. 会产生吃醋闹矛盾，无需手动触发**
旧熟人看到你和别的新角色相处，好感会下降、输出偏消极，会在帖子里和新角色冲突、对你表达不满，随剧情自动触发。

**6. 帖子为贴吧样式**：点开显示楼主正文 + 楼层评论区，支持收藏、手动回复、AI 生成角色回复。

**7. 4 个信息流板块**：全局 / 收藏 / 主页 / 管理 自由切换。

**8. 专属主页**：可设置个人昵称，主页只展示你发布的帖子，AI 不会冒充你发言。

**9. 公开 / 隐私两种发帖状态**。

**10. 社交记忆系统**：发布公开帖子后，AI 判断受影响角色，**记仇记好感**会改变角色好感并永久保存到档案；回复会读取过往恩怨，旧仇旧情体现到对话中；支持一键精简压缩人物记忆。

## 🎨 真图生图

- **可编辑提示词**：每次生成都有清晰可改的提示词面板，随手微调出想要的效果。

## 🎭 小剧场

- 让 AI 把某段剧情、某个场景、某个人物小传，用**一段沉浸式表演**呈现出来。

## 🎆 仪式注入台 · 符契系统

（v2.7+ 新增）一个独立的"场景模块库"，可手动开启一个个**符契（注入规则）**，让 AI 生成前注入特定约束，与记忆注入相互独立。每个符契可独立开关、编辑档位、设置注入位置（开头/对话中/末尾）。

| 符契 | 说明 |
|------|------|
| 🎲 **命运骰** | 跑团叙事判定：简单/困难两档，掷骰池+四档结果，思考过程折叠 |
| 🔥 **炼狱世界** | 地狱级生存法则：处处为难/人人怀疑/禁神话主角/绝境坚韧，带骰池判定 |
| 💖 **好感引擎** | 复杂化好感度系统：阶段区间/增减规则/阈值锁，原样/精简两档；**负好感**会真实影响角色对你的态度与行为 |
| 📊 **状态栏** | RPG 状态面板：全面版=全数值(精神/体力/魔力/行动力等)；好感版=各角色对用户好感 |
| 🌌 **平行世界** | 同一时刻主线之外的他处事件，丰富剧情视角 |
| 💬 **弹幕** | 观众实时吐槽：普通版=毒舌乐子人；黄色版=P站风格荤弹幕(只针对主角)，活人味十足 |
| 🔮 **伏笔** | 隐藏伏笔/铺垫，服务于未来剧情 |
| 🌐 **论坛** | 世界论坛·跨世界社区（详见上方章节）：各世界角色互刷/留言/跨世界吃醋 |
| 🖥️ **前端生成** | 用 HTML 具象化剧情界面/物品（手机聊天/书信/道具卡/HUD），直接可见 |

> 每个符契生成的动态内容默认用 `<details>` 折叠呈现（前端生成直接可见），不打断正文阅读。
> 全部提示词可编辑、可自建新符契、可一键恢复默认。

## 🧠 记忆与检索能力

- **RAG 向量检索**：剧情档案/角色日记向量化，命中相关回忆再注入
- **Rerank 重排**：OpenAI 兼容 `/rerank` 端点重排召回结果，失败自动降级
- **按登场人物注入**：正则识别剧情中出现的角色，只推这些角色的近期日记
- **选择性记忆（白名单）**：开启后只记「重点角色」，避免无关配角堆积
- **数据保护**：检测日记骤减自动从 localStorage 备份补回，防丢数据
- **总结瘦身（省 token）**：总结时默认只发送要总结的楼层，不再顺带注入历史日记/档案/世界书，大幅省 token；想要历史上下文可在设置「总结时注入历史」手动开启

## 🔧 其他亮点

- **三路并行 API** — 日记/关系/档案各自独立调用，单路失败不影响其他
- **自动 / 手动双模式** — 每 N 楼自动触发，也可手动指定范围补写
- **剧情时间线** — 主线/支线/状态/未解决分类展示，带时间标记，多行批量删除稳定可靠
- **章回导航** — 自动生成章回标题，支持翻阅历史版本
- **世界书联动** — 别名字符归一化，精准命中原绑定角色的世界书条目
- **回复结束提示音** — AI 回复完/总结后自动响铃，可自定义音频、三选一触发时机
- **回复后回到开头** — AI 回复后平滑滚动回开头（可开关）
- **心理补全 / 名场面收藏 / 成就系统 / 塔罗占卜** 等趣味功能
- **填表功能（LIWE 情报表）** — 可自定义字段，自动快照
- **护眼配色** — 米白藏青（日）/ 深藏青午夜（夜）双主题
- **全量迁移** — 导出/导入聊天记录 + 插件回忆，换设备不丢记忆
- **Token 统计与费用** — 日志面板显示每次调用的 Token、缓存命中、费用估算

## 📥 安装方法

```bash
cd SillyTavern/extensions/
git clone https://github.com/zhaoyichan/SillyTavern-Plugin-HCDiary.git character-diary
```

重启 SillyTavern 后，在扩展菜单中点击「角色日记」即可使用。

---

## 🚀 使用快速上手

1. 右上角滑块进入**设置**，配置 API 来源（默认跟随酒馆）
2. 正常聊天，AI 回复后插件自动检测并写日记（或点「写日记」手动触发）
3. 「浏览」视图：查看所有角色日记；「时间线」看剧情档案演进；「关系」看关系网
4. 「更多菜单 → 仪式注入台」：开启你想要的符契（命运骰、弹幕、论坛、前端生成等）
5. 「存档」：点「存一个新档」给当前角色建第一个存档，随时回档
6. 顶部「论坛」入口：进入**世界论坛**，点「总结当前剧情 · 保存世界」生成你的第一个世界档案，然后看各世界角色互刷帖子
7. 「日志」视图：查看 API 调用详情、Token 与费用统计

## 💾 数据存储

- 日记/关系/剧情档案存在 ST 的 `chatMetadata.extensions['character-diary']`，跟随聊天自动保存，并有 Chat Variables 双轨兜底
- 存档存在 IndexedDB（`cd-save-db`），告别 localStorage 容量瓶颈，随便存
- 世界论坛的世界/帖子/角色/称号存在 localStorage（`cd-forum-data`），换卡不丢
- 日志存储在浏览器 localStorage，刷新不丢失
- 可用「全量迁移」在换设备时完整搬迁记忆
