# 角色日记 (Character Diary)

一个 SillyTavern 插件，**自动为剧情中的每个角色撰写第一人称日记**。

## 它能做什么

每次 AI 回复后，插件会自动分析新增的剧情内容，并行执行三件事：

| 功能 | 说明 |
|------|------|
| **📖 角色日记** | 为每个有戏份的角色以第一人称写日记，包含心情、态度、心声、关键事件 |
| **🔗 关系网** | 提取角色之间的单向主观关系（友好/排斥/中立），生成力导向图 |
| **📜 剧情档案** | 增量更新主线/支线/状态/未解决事项，每次总结自动生成章回标题 |

## 主要特性

- **三路并行 API** — 日记、关系、剧情档案各自独立调用，互不影响，单路失败不影响其他
- **自动/手动双模式** — 可设置每 N 楼自动触发，也可手动指定楼层范围补写
- **不受分片加载影响** — 自动触发基于 chat.length 基线追踪，ST 分片加载不影响判断
- **剧情时间线** — 主线/支线/状态/未解决分类展示，保留时间线竖线样式
- **章回导航** — 每次总结自动生成章回标题，支持翻阅历史版本
- **世界书同步** — 日记内容自动同步到 ST 世界书
- **Token 统计与费用** — 日志面板显示每次 API 调用的 Token 用量、缓存命中、费用估算
- **测试工具** — 日志面板内置「三路API调试」和「检查自动触发」按钮
- **数据导入导出** — 支持 JSON/Markdown 导出，JSON 导入合并

## 安装方法

```bash
cd SillyTavern/extensions/
git clone https://github.com/zhaoyichan/SillyTavern-Plugin-HCDiary.git character-diary
```

重启 SillyTavern 后，在扩展菜单中点击「角色日记」即可使用。

## 使用方法

1. 点击右上角滑块图标进入设置，配置 API 来源（默认跟随酒馆连接）
2. 正常聊天，AI 回复后插件会自动检测并写日记
3. 也可点击「写日记」手动触发
4. 在「浏览」视图中查看所有角色的日记
5. 在「时间线」视图中查看剧情档案演进
6. 在「关系」视图中查看角色关系网
7. 在「日志」视图中查看 API 调用详情和费用统计

## 数据存储

日记数据存储在 SillyTavern 的 chatMetadata 中，跟随聊天自动保存。日志存储在浏览器 localStorage，刷新不丢失。
